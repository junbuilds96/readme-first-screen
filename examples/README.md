# Examples

These synthetic fixtures show what the scorer rewards in the first screen of a
README:

- [README-before.md](README-before.md) starts with badges and vague positioning.
- [README-after.md](README-after.md) opens with the project shape, target user,
  value, runnable command, sample output, and proof signals.
- [report.txt](report.txt) is generated by the current CLI with:

```bash
python -m readme_first_screen --baseline examples/README-before.md examples/README-after.md
```
